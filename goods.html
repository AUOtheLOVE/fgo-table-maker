소분을 하자

FGO → 확챠 →
숫자 표식
  • +숫자 버튼 또는 빈 곳 더블클릭 → 숫자 입력
  • 숫자 드래그 → 이동
  • 숫자 클릭 후 Delete → 삭제
  • 크기+ / 크기− → 숫자 전체 크기 조절
화이트 처리
  • 빈 곳 드래그 → 사각형 화이트
  • 다각형 버튼 → 클릭으로 점 찍기 → 첫 점 클릭 / 더블클릭 / Enter → 닫기
  • 화이트 클릭 → 선택 (이동·크기 조절, 다각형은 꼭짓점 조절)
  • 한 번 더 클릭 또는 더블클릭 → 사라짐
공통
  • Ctrl+Z → 되돌리기
  • Esc → 선택 해제
저장
  • 데이터는 이 브라우저에만 저장 (서버 전송 없음)
  • 다른 기기·브라우저에서는 안 보임
  • 브라우저 사이트 데이터 삭제 시 같이 사라짐
  • ⋯ → 백업 저장 → 파일로 보관
  • ⋯ → 이 소분 삭제 / 전체 데이터 삭제
이미지를 끌어다 놓거나 붙여넣기(Ctrl+V)
